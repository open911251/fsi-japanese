如何取得 API Key？
到 console.cloud.google.com 建立專案 → 搜尋並啟用「Cloud Text-to-Speech API」→ 「憑證」→「建立憑證」→「API 金鑰」，貼到上方即可。每月 WaveNet/Neural2 有 100 萬字元免費額度，個人練習幾乎用不完。Key 只存在你的瀏覽器（localStorage），不會上傳。
本地 AI 設定（選用：正誤回饋／開放應答）
接自己工作站的 Whisper／LLM（OpenAI 相容 API）。遠端機器用 ssh -L 埠轉發到 localhost 即可，瀏覽器允許 HTTPS 頁面連 localhost。伺服器需允許 CORS（Ollama 設 OLLAMA_ORIGINS=*；faster-whisper 可用 speaches 等 server；VOICEVOX engine 需加 --cors_policy_mode all）。設定只存在瀏覽器。
填了 VOICEVOX 後，腔調回饋會多一排逐拍高低標註（比對音高曲線更準的符號級評分，取自 VOICEVOX 對句子的重音分析），跟唱與錄音對比的畫布也會疊一條理論高低軌。沒填就照舊只有曲線比對。
